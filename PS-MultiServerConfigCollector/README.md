# PS-MultiServerConfigCollector

> **Status: In development**

PS-MultiServerConfigCollector will collect hardware and configuration details from multiple Windows servers and export them to a single report.

**Planned features:**

- CPU model, core count, and clock speed
- Total and available RAM
- Disk count, size, and free space
- Operating system version and build
- Export to CSV or formatted text report
- Runs without installing agents on target servers
