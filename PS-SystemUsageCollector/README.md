# PS-SystemUsageCollector

> **Status: In development**

PS-SystemUsageCollector will export live usage metrics from multiple Windows servers at once — a Task Manager view across your entire server fleet.

**Planned features:**

- CPU usage per server
- Memory usage (used, free, percentage)
- Disk I/O and network throughput
- Snapshot or continuous polling mode
- Export to CSV for trend analysis
